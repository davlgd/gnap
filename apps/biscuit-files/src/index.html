Biscuit files

Three processes: a GNAP authorization server, a file resource server and this client. Only synthetic data is used.

The AS grants read notes and write draft for 20 minutes. This fixed demonstration policy does not request resource-owner consent.

1. Request and use access

2. Restrict locally

Restrictions accumulate. They never grant new rights or change the client's key. No AS round trip is needed to attenuate.

3. Retire the authority

After proof verification and local rights checks, the AS checks the request's authority and reserves its nonce once for the client's key. No positive decision is cached. This application channel is not GNAP introspection; selective block revocation is not implemented.
