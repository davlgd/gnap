GNAP message diagnostics

Inspect an imported GNAP message, AS discovery response or RFC 9767 RS-facing message. A passing check is not a certification of an AS, RS or client. Core-message checks share SDK validators. AS discovery and RFC 9767 imports use separate HTTP/JSON assertions and shared registry data, not the SDK validators; the optional digest check shares gnap-crypto. Neither is a complete independent protocol implementation.

Test data only. Do not paste production access tokens, private keys, personal data or full authenticated traces. Imports are sent to this server over HTTPS in deployment. The application does not persist or log them; hosting infrastructure is outside this promise. Your browser may retain form contents.

Select the message actually captured. Request and response checks are distinct.

Bounded live AS/RS tests

Only exact endpoints preapproved by this service's operator are available. Choose a rejection test (AS malformed grant or RS credential-free GET), or AS discovery (one OPTIONS request). No redirects or credentials. Rejection alone cannot prove a working grant; discovery declarations cannot prove working capabilities. Global shared cooldown: 60 seconds per process across all operations. You cannot supply an arbitrary URL.

What this version does not test

No signature or replay verification, consent workflow, token lifecycle, authenticated introspection, rights enforcement, client discovery helper or actual RFC 9767 discovery publication. AS discovery checks the document, not execution of advertised features. RFC 9767 imports inspect message shapes and declared comparisons only; an imported active: true does not prove a token is active. Resource registration imports do not prove registration, reference resolution, compatible token formats or introspection support for the RS. Absent optional fields and unknown registry names produce not_tested with different explanations; neither is silently certified, and absence is not a missing-required-field failure. Shape checks alone do not cover every requirement. No imported URL is fetched. Live probes check normal TLS certificate verification only, not a complete TLS security audit.

References: RFC 9635, RFC 9767, IANA GNAP registries, and IANA Subject Identifier Formats.
