GNAP message diagnostics

Inspect an imported GNAP message or AS discovery response. A passing check is not a certification of an AS, RS or client. Message checks share SDK validators. Discovery checks use separate HTTP/JSON assertions and shared registry data, not the SDK discovery validator.

Test data only. Do not paste production access tokens, private keys, personal data or full authenticated traces. Imports are sent to this server over HTTPS in deployment. The application does not persist or log them; hosting infrastructure is outside this promise. Your browser may retain form contents.

Missing context is not tested. Optional capability lists may be omitted. HTTP loopback remains a development deviation, not a conformant discovery endpoint.

Bounded live AS/RS tests

Only exact endpoints preapproved by this service's operator are available. Choose a rejection test (AS malformed grant or RS credential-free GET), or AS discovery (one OPTIONS request). No redirects or credentials. Rejection alone cannot prove a working grant; discovery declarations cannot prove working capabilities. Global shared cooldown: 60 seconds per process across all operations. You cannot supply an arbitrary URL.

What this version does not test

No signature or replay verification, consent workflow, token lifecycle, RS introspection or discovery (RFC 9767), rights enforcement, or client discovery helper. AS discovery checks the document, not execution of advertised features. Optional lists not announced and unknown registry names produce not_tested with different explanations; neither is silently certified. Shape checks alone do not cover every requirement. No imported URL is fetched. Live probes check normal TLS certificate verification only, not a complete TLS security audit.

References: RFC 9635, RFC 9767, IANA GNAP registries, and IANA Subject Identifier Formats.
