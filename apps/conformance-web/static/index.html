GNAP message diagnostics

Inspect an imported GNAP message. A passing check is not a certification of an AS, RS or client. This tool shares gnap-types and gnap-crypto with the reference implementation; it is not an independent oracle.

Test data only. Do not paste production access tokens, private keys, personal data or full authenticated traces. Imports are sent to this server over HTTPS in deployment. The application does not persist or log them; hosting infrastructure is outside this promise. Your browser may retain form contents.

Bounded live AS/RS tests

Only exact endpoints preapproved by this service's operator are available. AS: one unsigned malformed grant request. RS: one credential-free GET against a declared protected resource. No redirects or credentials. This checks rejection only, not a working grant, valid token, rights or introspection. A deny-all server can pass. Global shared cooldown: 60 seconds per process. You cannot supply an arbitrary URL.

What this version does not test

No signature or replay verification, consent workflow, token lifecycle, RS introspection, rights enforcement or discovery. Absent optional fields produce not_tested, not a pass. Shape checks alone do not cover every requirement. No imported URL is fetched. Live probes check normal TLS certificate verification only, not a complete TLS security audit.

References: RFC 9635 and RFC 9767.
