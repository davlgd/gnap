GNAP message diagnostics

Inspect an imported GNAP message. A passing check is not a certification of an AS, RS or client. Core-message checks share SDK validation. RFC 9767 imports use separate JSON assertions and shared registry data; the optional digest check shares gnap-crypto. Neither is a complete independent protocol implementation.

Test data only. Do not paste production access tokens, private keys, personal data or full authenticated traces. Imports are sent to this server over HTTPS in deployment. The application does not persist or log them; hosting infrastructure is outside this promise. Your browser may retain form contents.

Select the message actually captured. Request and response checks are distinct.

Derivation imports inspect selected grant-message fields only. They do not prove parent-token validity, RS1 authentication, downstream rights, audience or revocation linkage. Continuation, interaction and error responses are not successful issuance observations.

Optional caller-declared comparison context

This is your declaration, not verified network or token evidence. No URL is fetched. Leave blank when unknown. Context cannot override a contradiction in the message.

Bounded live AS/RS tests

Only exact endpoints preapproved by this service's operator are available. AS: one unsigned malformed grant request. RS: one credential-free GET against a declared protected resource. No redirects or credentials. This checks rejection only, not a working grant, valid token, rights or introspection. A deny-all server can pass. Global shared cooldown: 60 seconds per process. You cannot supply an arbitrary URL.

What this version does not test

No signature or replay verification, consent workflow, token lifecycle, authenticated introspection, rights enforcement or actual discovery publication. RFC 9767 imports inspect message shapes and declared comparisons only; an imported active: true does not prove a token is active. Resource registration imports do not prove registration, reference resolution, compatible token formats or introspection support for the RS. Absent optional fields produce not_tested, not a missing-required-field failure. Shape checks alone do not cover every requirement. No imported URL is fetched. Live probes check normal TLS certificate verification only, not a complete TLS security audit.

References: RFC 9635 and RFC 9767.
